# AdFree-Music

**U-Music** is a modern, open-source music streaming web application built with **C# .NET 8**. It delivers a premium music listening experience inspired by platforms like Apple Music, Spotify, and YouTube Music while providing a fast, responsive, and intuitive interface.

The application is designed with a clean architecture, high performance, and responsive UI that works seamlessly across mobile phones, tablets, laptops, desktops, and large-screen TVs.
